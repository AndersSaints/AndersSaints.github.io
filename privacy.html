Privacy Policy

Hidden Value Uploader · last updated 31 October 2026

Hidden Value Uploader is a private tool used only by the owner of the Hidden Value YouTube channel to upload and schedule its own videos and read its own channel analytics. It is not offered to the public and no one else signs in to it.

What data it accesses

  • The owner's YouTube channel, to upload videos, thumbnails, captions and comments (YouTube Data API).
  • The owner's channel analytics, to measure how videos perform (YouTube Analytics API).

How it is stored

The access token is stored only on the owner's computer. No data is sold, shared with third parties or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions: via the contact details on the channel's About page.
